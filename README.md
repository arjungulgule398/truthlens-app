# TruthLens - Misinformation Triage Platform

## Track
Track 2: Real-World AI Products (Civic Tech)

## Hackathon ID
[AZIS-CPYCTC]

## Tech Stack
HTML5, Tailwind CSS, JavaScript (Vanilla ES6), Web LocalStorage API.

## How to Run
1. Open `index.html` in any web browser, or access the live deployed Vercel URL.
2. Submit a viral claim text along with platform and category selections.
3. Test auto-risk detection by using sensational words (e.g., "breaking", "SHOUTING TEXT", or omitting source link).
4. Use the reviewer status actions to mark claims as True, False, or Misleading.
